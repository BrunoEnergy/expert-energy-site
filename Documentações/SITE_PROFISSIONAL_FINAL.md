## 🚀 COMO TESTAR

### Teste Rápido (2 minutos)

1. **Abrir `index.html`** no navegador
2. **Verificar logo** no header (canto superior esquerdo)
3. **Rolar a página** - verificar animações suaves
4. **Clicar no chatbot** - verificar layout estável
5. **Modo mobile** (F12 → Device Toolbar → iPhone)
   - Menu mobile funciona?
   - Header compacto?
   - Chatbot adaptado?

### Teste Completo (10 minutos)

1. **Navegação**: Testar todos os links do menu
2. **Páginas**: Abrir todas as 10 páginas
3. **Formulário**: Testar `analise.html`
4. **Chatbot**: Testar todas as 7 opções
5. **Tema**: Alternar modo claro/escuro
6. **Mobile**: Simular iPhone, iPad, Galaxy
