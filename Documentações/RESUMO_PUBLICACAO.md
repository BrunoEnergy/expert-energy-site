## 🎯 Os 6 Passos Essenciais

### 1️⃣ Criar Conta no GitHub
- Acesse: https://github.com/signup
- Cadastre-se com seu email
- Confirme o email
- **Tempo:** 2 minutos

### 2️⃣ Criar Repositório
- Clique no **"+"** → **"New repository"**
- Nome: `expert-energy-site`
- Tipo: **Public**
- Clique **"Create repository"**
- **Tempo:** 1 minuto

### 3️⃣ Fazer Upload dos Arquivos
- Clique **"uploading an existing file"**
- Arraste TODOS os arquivos do projeto
- Escreva: "Site Expert Energy v4.0"
- Clique **"Commit changes"**
- **Tempo:** 3 minutos

### 4️⃣ Ativar GitHub Pages
- Vá em **Settings** → **Pages**
- Source: **Branch `main`** → **`/ (root)`**
- Clique **"Save"**
- **Tempo:** 1 minuto

### 5️⃣ Aguardar Deploy
- Aguarde 2-3 minutos
- GitHub processa automaticamente
- **Tempo:** 3 minutos

### 6️⃣ Acessar Seu Site!
- URL: `https://SEU-USUARIO.github.io/expert-energy-site/`
- Pronto! Site no ar! 🎉
- **Tempo:** 0 minutos
